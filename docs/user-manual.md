# Rover 用户手册

Rover 是二维虚拟小车。单人可以在一台电脑上练习。局域网联机时，由一台电脑运行车端服务，桌面用户登录同一车端后可以观察，获得操作者角色的用户可以申请控制权。

## 下载与打开

从同一个 Release 下载你需要的文件。Windows 请完整解压 ZIP，双击其中的 EXE，并保留它旁边的 `_internal` 目录。 [GitHub Release v0.1.0](https://github.com/must-dsnet-lab/network-programming-project/releases/tag/v0.1.0)

| 文件 | 谁使用 | 打开 |
| --- | --- | --- |
| `RoverDesktop-win64.zip` | Windows x64 桌面用户 | `RoverDesktop.exe` |
| `RoverVehicleAdmin-win64.zip` | Windows x64 车端部署人员 | `RoverVehicleAdmin.exe` |

Windows 发布包自带运行依赖。单人使用「本地模拟」只需桌面包。首次联机由车端部署人员完成下方[车端部署](#车端部署)，再将连接包交给各桌面用户。

## 桌面端使用

### 选择启动方式

| 启动页入口 | 适用场景 |
| --- | --- |
| 本地模拟 | 启动本机虚拟车。等到「遥测可用」，选择数值控制或二维驾驶，再点「开始／应用」。关闭窗口会结束本机虚拟车。 |
| 连接车端 | 联机使用「用户版（自动遥测）」。观察员和操作者都从这里登录，系统自动安排遥测接收端口。 |
| 只读观察（手动遥测） | 接收车端已发往固定目的地的 UDP 遥测。填写的是**本机** IPv4 和车端预设的目标 UDP 端口，再点「开始接收」。用户版的日常观察使用上一行的登录方式。 |

高级模式和专家模式用于已有实验车端，遥测配置随车端设置填写。 [桌面模式与固定遥测说明](../README.md#desktop-windows-starter)

### 导入连接包并登录

1. 从车端部署人员处拿到 `.rover-connection.json` 和该车端显示的公开 CA SHA-256 指纹。打开「连接车端」，点击「导入连接包…」并选择文件。程序将切换到「用户版（自动遥测）」并填好地址、端口和证书配置。
2. 第一次信任该 CA，或部署人员更换 CA 时，会看到「确认信任车端 CA」。与部署人员通过可信渠道核对指纹，完全一致再确认。
3. 初次使用时填写账号和凭据，点「注册账号」。成功后重新输入同一个凭据。已有账号可直接填写自己的凭据。
4. 如需保留地址、端口、CA 路径和账号，可先勾选「保存连接配置」。点「连接」，等待「遥测可用」，核对界面显示的账号角色和实测速度。凭据每次连接时重新填写。

账号长度为 1–64 个字符，以英文字母或数字开头，其余可用英文字母、数字、下划线、点或连字符。凭据至少 12 个字符，UTF-8 编码后最多 1024 字节。新注册账号为「观察员」，可查看地图、轨迹和车辆状态。要驾驶，请让部署人员将账号设为「操作者」，再用原账号和凭据登录。 [注册、角色与遥测](../README.md#two-dimensional-user-edition)

### 驾驶、停车与交接

操作者等遥测可用后，先点「申请控制权」。获权后选择操纵方式，再点「开始／应用」。当前有人驾驶时，可请对方「归还」或发起「交接」。需要连续驾驶时可勾选「操纵期间自动续期」。

| 操纵方式 | 用法 |
| --- | --- |
| 数值控制 | 填写目标速度和目标朝向，点「开始／应用」。地图与「车辆遥测」显示车端实际状态。 |
| 二维驾驶 | 点「开始／应用」后拖动方向、油门或刹车控件，也可按住 `A`／`D` 转向、`W` 加油、`S` 刹车。松开油门后车辆会滑行减速。窗口失焦会制动并暂停驾驶，重新聚焦后再点「开始／应用」。 |

- **结束本次驾驶**。点「正常停车」，等实测速度归零。有控制权时可点「归还」，让其他操作者自行申请。
- **直接交给队友**。请接手方先以操作者登录并等到遥测可用。当前持有者点「交接」。多名候选人时选择接手方，一名候选人时直接发起交接。车端确认零速后授予接手方控制权，接手方再点「开始／应用」才会起步。
- **紧急停车**。点「急停」可请求车端停车并锁存。「停止发包」会结束周期控制，让车端在控制超时后按保护规则停车。恢复时待会话和遥测可用，由操作者点「显式复位」。确认「未锁存」后，按界面提示重新申请控制权，再点「开始／应用」。

地图可用滚轮缩放、拖动平移。「定位车辆」把画面移到车辆当前位置，「清除轨迹」清除本窗口的历史线条。 [二维驾驶说明](../README.md#desktop-2d-driving)

## 车端部署

### 启动车端

1. 将车端电脑和桌面电脑接入可互访的局域网，优先使用同一个家庭路由器或允许设备互访的热点。打开 `RoverVehicleAdmin.exe`。在服务停止时点「检测本机 IP」，选择当前 Wi-Fi 或有线网卡的实际内网 IPv4。 `127.0.0.1` 用于同机调试。
2. 点「生成／更新证书」，等「证书目录」自动填入。初次部署可使用默认账号数据库。已有账号时沿用原来的数据库路径。双方的默认管理端口为 `19177/TCP`，控制端口为 `9999/UDP`。按需修改时，之后导出的连接包会携带新端口。
3. 点「启动车端」，等状态显示「车端运行中」。Windows 发布版在为所选私有 IPv4 缺少匹配规则时会提示「允许局域网访问」。确认后完成 Windows 管理员授权。规则只放行本地子网到该 EXE 的管理 TCP 和车端 UDP，已匹配的规则会复用。保留 Windows 防火墙开启。
4. 点「导出连接包」，将保存的 `.rover-connection.json` 和界面上可复制的公开 CA SHA-256 指纹发给桌面用户。连接包包含车端地址、端口和公开 CA。车端证书目录内的私钥及账号数据库由部署人员保管。

换网或 IPv4 变化时，等车辆归零并停止车端。重新选 IP、生成／更新证书、启动车端并导出新的连接包。图形签发沿用已有部署 CA，桌面重新导入即可更新地址和端口。公用网络的放行规则还绑定所选本机地址，换地址时程序会重新检查。 [签发与 Windows 局域网放行](../README.md#lan-connection-provisioning)

### 管理账号与会话

- 桌面用户注册后，在车端「账号权限」输入已注册账号，选择「操作者」并点「更新角色」。让对方重新登录。需要还原观察权限时，按同一流程改为「观察员」。
- 用「桌面会话」查看账号、角色、管理连接、UDP 遥测接收端点及控制权。点击一行可查看近期会话事件。「遥测发送」列的「已发送」表示车端已尝试并成功发出数据报，桌面侧以「遥测可用」确认实际收到。
- 结束联机时，先让车辆归零，再点「停止车端」。

| 数据 | 默认位置 |
| --- | --- |
| Windows 车端账号库 | `%LOCALAPPDATA%\RoverVehicle\accounts.sqlite3`，实际路径见「账号数据库」。 |
| Windows 车端的图形签发材料 | `%LOCALAPPDATA%\RoverVehicle\tls`，当前车端证书路径见「证书目录」。 |
| 已保存的桌面配置与公开 CA | 当前用户的 Qt 配置目录内 `Rover/desktop-connection.json` 和 `Rover/trusted-vehicle-ca/`。 |
| 本地模拟日志 | 当前用户的 Qt 数据目录内 `Rover/logs/`，实际路径见桌面状态说明的提示。 |

## 连接故障速查

| 显示或现象 | 先核对 |
| --- | --- |
| 「无法连接车端」或注册连接报错 | 确认「车端运行中」、双方网络允许互访、桌面导入的是当前连接包。管理连接走车端配置的 TCP 端口，默认 `19177`。校园 Wi-Fi 或热点可能限制设备互访。 |
| 「证书校验失败」 | 向部署人员核对当前 CA 指纹和连接包。换了车端地址时，让部署人员为该地址更新证书后重新导出。 |
| 「未收到车端遥测登记确认」或等不到遥测 | 用户版登录使用管理 TCP，自动登记及遥测回传使用 UDP。核对车端启动时的局域网放行、双向 UDP、桌面是否为用户版及车端会话表的遥测端点。动态登记端口由车端分配，`9999/UDP` 是默认控制端口，单独放行它无法替代遥测登记。 |
| 能看到遥测，车辆不动 | 查看角色和控制权持有者。操作者需获权后点「开始／应用」。若显示「已锁存」，按上文复位。操控仍失败时，再核对车端控制 UDP 端口。 |
| 「监听失败」 | 使用手动遥测时，关闭占用同一监听地址和端口的旧窗口。连接用户版时优先使用系统自动分配的端口。 |

需要确认管理端口可达时，可在桌面电脑运行下列对应命令，将 `192.168.1.20` 和 `19177` 换成车端的实际地址和管理端口。测试成功表示 TCP 可达，TLS 校验和 UDP 遥测由登录流程继续确认。 [局域网部署与故障记录](../README.md#lan-connection-provisioning)

```powershell
Test-NetConnection -ComputerName 192.168.1.20 -Port 19177 -InformationLevel Quiet
```

```bash
nc -vz -G 5 192.168.1.20 19177
```

## macOS 桌面端

在同一个 Release 下载 `Source code (zip)`。用 macOS 14 或更新版本及 Python 3.12 或更新版本，在解压后含 `pyproject.toml` 的目录中运行下列命令。打开启动页后，按[导入连接包并登录](#导入连接包并登录)使用。 [跨平台源码指南](cross-platform-reproduction.md#2-一次性准备)

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install .
./.venv/bin/python -m rover.desktop.app --launcher
```
